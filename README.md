Tic-Tac-Toe in Next.js
A sleek, interactive Tic-Tac-Toe game built with Next.js and React. Play in real-time, track Xs and Os, and see the winner instantly. Need a fresh start? Hit reset and jump back in!

Highlights:

Client-side interactivity powered by React useState

Instant winner detection

Turn-based gameplay with Xs and Os

Quick reset for endless fun

Fully compatible with Next.js’s client-side rendering ('use client')


A simple yet polished way to showcase your Next.js skills while having some gaming fun!
